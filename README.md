# VEILBOUND

VEILBOUND is an original browser-based action-adventure RPG set in the ruined world of Eidol.

A masked relic hunter named Kael carries a damaged Shardblade and an ancient mechanical gauntlet known as the Axiom. When the Axiom awakens, long-dormant systems beneath the world begin responding to him.

## Current Production Goal

Build a polished vertical slice spanning Greyhaven, the Hollow March, and the Sunken Archive. The slice must prove movement, combat, room transitions, persistent world state, dialogue, puzzles, ability gating, Tether traversal, a multi-phase boss, saving, and touch/desktop input.

## Production Documents

The project will maintain its canon, agent responsibilities, technical architecture, and vertical-slice plan as version-controlled Markdown documentation.

**Status:** Pre-production / foundation.
